What WildID writes to your Lightroom catalog

WildID adds keywords, collections and a few metadata fields to the photos you run it on. It never changes a photo file, your develop settings or your own keywords.

Keywords

Each identified photo gets the top answer as a keyword hierarchy: the class, the genus and the species under one root keyword.

WildID
└─ Mammalia
   └─ Panthera
      └─ Panthera onca      synonym: Jaguar
  • The common name is stored as a synonym of the species keyword. A search for “jaguar” finds the photo, and Lightroom can include synonyms when you export.
  • Photos judged to contain an animal also get the plain keyword animals. They get wildlife as well unless the species is a domestic one, such as a dog, a cat, cattle or a horse.
  • Photos worth a second look get WildID › review.
  • The root name WildID can be changed in the Identify dialog.

Collections

Under a collection set of your choice, WildID by default, the plugin keeps a tree: a set for each class, inside it a set for each genus, and at the bottom a collection for each species that holds the photos.

WildID
├─ Mammalia
│  ├─ Acinonyx
│  │  └─ Acinonyx jubatus — Cheetah
│  └─ Panthera
│     ├─ Panthera leo — Lion
│     └─ Panthera onca — Jaguar
├─ Reptilia
│  └─ Furcifer
│     └─ Furcifer pardalis — Panther Chameleon
└─ _review

Selecting a class or a genus set shows every photo below it. That is how a whole group is run again with the other model: select Mammalia, then Identify. These are ordinary collections, not smart collections. You can rename or delete them, and the plugin creates again what it needs.

Metadata fields

In the Metadata panel, under All Plug-in Metadata, each identified photo shows the WildID species, common name, class, score, status, model and time of the run. The status is ok, review, or reviewed once you have marked the photo. Status and class can be used in the Library filter and in smart collections, for example “WildID status is review”.

Running it again on the same photos

The WildID keyword branch and the two plain keywords belong to the plugin. A new run on a photo replaces what an earlier run left there: the old species keyword goes, a review flag that no longer applies goes, and the photo moves from its old species collection to the new one. The summary says how many photos moved.

Every other keyword stays untouched. Keep keywords of your own outside the WildID branch, including a species you corrected by hand.

The review workflow

  1. Open WildID / _review.
  2. Check each photo and correct the name by hand where the model was wrong.
  3. Select the photos you have dealt with and choose WildID: mark as reviewed.

Marking removes the photos from _review, takes off the review keyword and sets the status to reviewed. The collection and keyword changes can be undone with Edit → Undo.

What is skipped

  • Virtual copies and videos.
  • Photos whose original file is offline. If such a photo has a Smart Preview, WildID identifies it from the Smart Preview.

The summary after each run counts what was skipped.

What WildID never touches

  • The photo files themselves, RAW or JPEG.
  • Develop settings, ratings, flags, colour labels, titles and captions.
  • Keywords outside its own branch and its two plain keywords.

Tick Dry run in the Identify dialog to see the counts without anything being written.

The menu entries

All five are under Library → Plug-in Extras and again under File → Plug-in Extras.

Identify species with WildID…
Identifies the selected photos and writes the results.
WildID: mark as reviewed
Clears the review markers on the selected photos.
WildID: prefetch place list…
Fetches the species list for a place. The only entry that uses the internet.
WildID: server status…
Shows whether the engine is running, with its models and its memory, and starts or stops it.
WildID: delete empty collections…
Removes the empty species collections and sets that re-runs leave behind, after showing you the list.

WildID

Species identification for wildlife photos, in Lightroom Classic and on the command line. Free and open source under the AGPL-3.0 licence.

Recognition by BioCLIP 2 from the Imageomics Institute. Animal detection by MegaDetector. Species lists from iNaturalist, with names matched against the GBIF Backbone Taxonomy.
