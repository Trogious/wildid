Licence and credits

WildID is free and open source. It stands on models, data and software that other people published openly, and this page names them.

Free and open source

WildID is free software under the GNU Affero General Public License, version 3 or later. That covers the engine, the Lightroom plugin and the installer.

  • You may use it for any purpose, paid photography work included, at no cost.
  • You may read, change and share the source code.
  • If you pass on a changed version, or run one as a service for other people, you must publish your changes under the same licence.

The source code is on GitHub, and every release there carries the installer next to the source it was built from. WildID comes without any warranty.

Citing the model

If you use WildID’s identifications in published work, cite the model that made them: Gu et al., “BioCLIP 2: Emergent Properties from Scaling Hierarchical Contrastive Learning”, arXiv:2505.23883.

WildID

Species identification for wildlife photos, in Lightroom Classic and on the command line. Free and open source under the AGPL-3.0 licence.

Recognition by BioCLIP 2 from the Imageomics Institute. Animal detection by MegaDetector. Species lists from iNaturalist, with names matched against the GBIF Backbone Taxonomy.
